# Java Bank Console

Java로 구현한 간단한 콘솔 기반 은행 시스템입니다.  
객체지향 프로그래밍을 연습하며 계좌 생성과 입출금 등 기본적인 은행 업무를 구현했습니다.

## 주요 기능

- 계좌 생성
- 계좌 목록 조회
- 계좌번호를 이용한 계좌 검색
- 입금
- 출금
- 잔액 조회
- 콘솔 메뉴를 통한 기능 선택

## 기술 스택

- Java
- Java Collections
- 객체지향 프로그래밍(OOP)
- 콘솔 입출력
